# 决策记录

## 2026-09-02 — 独立工作树

成语接龙留在 `feature/chengyu-play`。本玩法用第二份 git worktree 和 `feature/pokemon-pokedex`，从上游 `main` 拉出。两套目录不要合并。

## 2026-09-02 — 只做第一世代

151 条已经是 Flash 和字库问题。后续世代等这套上了真机再说。

## 2026-09-02 — 加资源分区，不砍应用分区

保持 3 MB factory 应用。图片和叫声放 `pokedexfs`，地址 `0x35A000`、大小 `0x3A6000`，末端正好顶上 Recovery。这样小程序 BLE 安装还能用。

## 2026-09-02 — 离线图鉴

胸牌有 Wi-Fi，但 V1 运行时不联网。完整本地目录更简单、更省 RAM，聚会没网也能查。

## 2026-09-02 — legacy 叫声 + IMA-ADPCM

用 PokeAPI 的 legacy OGG（偏初代音色）和 IMA-ADPCM，不上 Opus。音效钥匙扣的经验说明 Opus 适合数小时语音；151 段一秒叫声不值得上解码器。

## 2026-09-02 — 「我是谁」当缓存，不当产品

名称、介绍和官方立绘已经在「我是谁」里。这里只复制并转换 1–151。不要把那个网页猜谜做成这块胸牌的固件。

## 2026-09-02 — 特性用现代名称

初代对战没有特性。图鉴仍然展示现代特性名：空白「特性」行，不如一行后世名称。

## 2026-09-02 — 进化链留在 1–151 内

PokeAPI 的进化链会带上后世形态（皮丘、后续伊布进化）。V1 丢掉全国编号超出 1–151 的节点，让图鉴和第一世代名册一致。

## 2026-09-02 — 先上文字版真机

立绘和叫声不是验证按键、翻页和中文显示的前提。先刷一版开机进图鉴的文字固件；手感对了再补图和声音。

## 2026-09-02 — V1 不做按名搜索

三个键打不了字。顺序翻页加随机，已经覆盖这次要的交互。

## 2026-09-02 — 手持图鉴外壳，80x80 拆包立绘

真机确认按键流程可用后，界面改成红色手持图鉴，不再用模板天空/草地。立绘做成 80×80 RGB565，并拆成 `sprites1.bin` / `sprites2.bin`，避免单个 SPIFFS 文件超过分区一半。叫声仍用 legacy OGG → IMA-ADPCM。已写身份的胸牌只许 `idf.py flash` 分段写，禁止把带 `pokedexfs` 的 merged `full.bin` 从 `0x0` 整包刷进去。

## 2026-09-02 — 全部升级招式和现代克制表

招式页列出红绿（缺则黄 / 火红叶绿）的全部升级自学招式，不再只留后期 8 个。能力值显示六项总和。克制页用现代属性表，因为目录里已经是现代属性（含妖精、钢）。

## 2026-09-02 — 新字段放进现有页，不加第七页

身高和体重放封面，旁边只写性别比。捕获率留在目录里，界面不显示。特性名和介绍放能力页，并写成「特性：」。第二句图鉴在与介绍不重复时放介绍页。世界小知识是首页第三个入口，进去后随机一条，上下键翻池子，不显示第几条。招式威力和招式说明不加。
